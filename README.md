# Medication Tracker

Open source iOS app for medicines, vitamins and supplements. Add a dose, put it on a schedule or leave it as-needed, group things into a treatment plan, get a reminder, and keep the history.

Local only. No account. Not medical advice.

The build prompt (every screen, field and flow) lives in [issue #1](https://github.com/jusso-dev/medication-tracker/issues/1).
